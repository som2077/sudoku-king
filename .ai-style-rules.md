# AI Code Style Rules

## [Golden Files]
- [src/components/Board.tsx](file:///home/som2077/Desktop/sudoku-king/src/components/Board.tsx) — Exemplar for React Native board geometry, cell mapping, and component structure.
- [src/components/Text.tsx](file:///home/som2077/Desktop/sudoku-king/src/components/Text.tsx) — Mandatory typography wrapper mapping `fontWeight` to Bricolage Grotesque fonts and resetting `fontWeight` for iOS compatibility.
- [src/store/useGameStore.ts](file:///home/som2077/Desktop/sudoku-king/src/store/useGameStore.ts) — Exemplar for Zustand store pattern with MMKV persistence, bitmask notes handling, and Firebase integration.
- [src/utils/sudokuLogic.ts](file:///home/som2077/Desktop/sudoku-king/src/utils/sudokuLogic.ts) — Exemplar for pure algorithmic utilities, deterministic PRNG (`cyrb128`, `mulberry32`), and board validation.

## [Naming & State-Control Rules]
- **Typography Invariant**: Never import `Text` from `react-native`. Always import `Text` from `src/components/Text` or the appropriate relative path.
- **State Management**: Centralize interactive game state in [useGameStore.ts](file:///home/som2077/Desktop/sudoku-king/src/store/useGameStore.ts) using Zustand and persist via MMKV (`react-native-mmkv`).
- **Notes Bitmask**: Sudoku pencil notes are represented as a bitmask number (`1 << num`), where bits 1–9 represent notes.
- **Secrets & API Keys**: Obfuscate sensitive strings and keys in [secrets.ts](file:///home/som2077/Desktop/sudoku-king/src/utils/secrets.ts) via hex encoding and runtime decoding (`decodeHex`). Use [scripts/obfuscate.js](file:///home/som2077/Desktop/sudoku-king/scripts/obfuscate.js) to generate new hex values.
- **Component File Structure**:
  1. External library imports (`react`, `react-native`, icons, expo modules)
  2. Custom internal component imports (specifically [Text](file:///home/som2077/Desktop/sudoku-king/src/components/Text.tsx))
  3. Store and utility imports
  4. Type definitions and constants
  5. Component definition (`export default function` or `export function`)
  6. Stylesheet (`StyleSheet.create`) or inline styles

## [DONTs]
- **DO NOT** import `{ Text }` from `'react-native'` anywhere in UI code.
- **DO NOT** commit raw API keys or ad unit IDs directly in plain text; use [secrets.ts](file:///home/som2077/Desktop/sudoku-king/src/utils/secrets.ts).
- **DO NOT** modify Expo configuration without checking Expo SDK 57 documentation per [AGENTS.md](file:///home/som2077/Desktop/sudoku-king/AGENTS.md).
- **DO NOT** mutate `board` or `history` directly in Zustand actions; always return new array/object references.
